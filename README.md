# 🛍️ Customer Shopping Behavior Analysis

An end-to-end Data Analytics project using **Python, MySQL, SQL, and Power BI** to analyze customer shopping behavior and generate business insights.

---

## 📌 Project Overview

This project analyzes customer shopping data to understand:

- Customer purchasing patterns
- Product performance
- Customer segments
- Subscription behavior
- Revenue contribution

---

## 🛠️ Tools Used

- Python
- Pandas
- MySQL
- SQL
- Power BI

---

## 📊 Dataset

- 3,900 customer records
- 18 columns
- Customer demographics
- Purchase details
- Shopping behavior

---

## 🔄 Project Workflow

```
CSV Dataset
      ↓
Python (Data Cleaning)
      ↓
MySQL Database
      ↓
SQL Analysis
      ↓
Power BI Dashboard
```

---

## 📈 SQL Analysis

Business questions answered:

- Revenue by gender
- Top-rated products
- Customer segmentation
- Subscription analysis
- Revenue by age group
- Top-selling products
- Discount analysis

---

## 📊 Power BI Dashboard

The dashboard includes:

- KPI Cards

## 💡 Key Insights

- Clothing generated the highest revenue.
- Young Adults contributed the highest revenue.
- Express Shipping customers spent slightly more.
- Most customers belonged to the Loyal segment.
